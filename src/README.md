# Source Code (`src/`)

Reusable Python modules extracted from validated notebooks and benchmark scripts—such as GLORIA ID-safe table loaders, radiometric helpers ($R_{rs}$, AVW, CIE 1931 chromaticity, QWIP), sensor spectral response function (SRF) convolution, optical water type wrappers, and leakage-resistant cross-validation splitters.

Keep exploratory one-off code in [`notebooks/`](../notebooks/) until abstractions are tested across at least two experiments.
